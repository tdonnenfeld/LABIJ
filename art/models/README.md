# Original LABIJ model assets

The character glTF files are generated entirely from original geometry in `tools/generate_characters.mjs`. No third-party meshes, textures or animation data were copied. The runtime adds a shared procedural 16×16 grain texture and animates named pivots. Regenerate from the repository root with Node.js. All model assets follow the repository's licensing terms. Existing sound credits remain in `art/audio/CREDITS.md`.
